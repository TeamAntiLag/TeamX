## Sobre o TeamX

O **TeamX** é uma ferramenta avançada de otimização, manutenção e personalização do Windows desenvolvida pela **Team AntiLag**.

Criado para usuários que querem ter mais controle sobre o próprio sistema, o TeamX reúne em uma única aplicação recursos para **otimização do Windows, limpeza, gerenciamento de inicialização, serviços, rede, privacidade, ajustes do sistema e configurações voltadas para jogos**.

A proposta é simples:

> **Mais controle. Menos processos desnecessários. Um Windows mais limpo, rápido e personalizado.**

O TeamX foi desenvolvido pensando tanto em usuários comuns que querem simplificar a manutenção do computador quanto em usuários avançados que desejam controlar cada detalhe do sistema.

---

## ⚡ Principais recursos

O TeamX possui diversos módulos independentes para diferentes áreas do Windows.

### 🚀 Otimizações

Aplicação de ajustes voltados para desempenho e responsividade do sistema.

* Otimizações do Windows
* Ajustes de desempenho
* Configurações do sistema
* Ajustes de energia
* Configurações de memória
* Ajustes relacionados a jogos
* Otimizações de inicialização
* Configurações avançadas do sistema

---

### 🧹 Debloat

Remova componentes e aplicativos desnecessários do Windows de forma organizada.

* Aplicativos pré-instalados
* Componentes opcionais
* Aplicativos da Microsoft
* Recursos desnecessários
* Pacotes selecionados pelo usuário
* Remoção segura e controlada

O sistema de Debloat foi projetado para permitir que o usuário escolha exatamente o que deseja remover, evitando alterações desnecessárias no sistema.

---

### ⚙️ Serviços

Gerencie serviços do Windows diretamente pelo TeamX.

* Visualização de serviços
* Identificação de serviços
* Ativação e desativação
* Configuração de inicialização
* Ajustes voltados para desempenho
* Controle sobre serviços desnecessários

---

### 🔌 Inicialização

Controle os aplicativos executados junto com o Windows.

* Aplicativos de inicialização
* Entradas do Registro
* Pastas de Startup
* Status de inicialização
* Ativação e desativação
* Informações sobre cada entrada

O objetivo é reduzir inicializações desnecessárias e acelerar o processo de boot.

---

### 🌐 Rede

Ferramentas para gerenciamento e otimização da conectividade do Windows.

* Ajustes de rede
* Configurações TCP/IP
* DNS
* Adaptadores de rede
* Limpeza de configurações
* Ajustes relacionados à latência
* Diagnóstico de conectividade

---

### 🎮 Game Mode

Um ambiente voltado para usuários que utilizam o computador principalmente para jogos.

O TeamX pode aplicar configurações específicas para reduzir processos desnecessários e priorizar uma experiência mais consistente durante a utilização de jogos.

---

### 🧽 Cleaner

Ferramentas para limpeza e manutenção do sistema.

* Arquivos temporários
* Cache
* Arquivos residuais
* Logs selecionados
* Arquivos desnecessários
* Limpeza de componentes específicos

---

### 🔍 Scanner

Identifique informações e possíveis pontos de otimização do sistema.

O Scanner ajuda a entender o estado atual do Windows antes de aplicar determinadas alterações.

---

### 🛠️ Tweaks

Uma coleção de ajustes avançados para personalizar o comportamento do Windows.

Entre os diferentes tipos de ajustes estão:

* Interface
* Sistema
* Privacidade
* Desempenho
* Explorer
* Windows Update
* Telemetria
* Experiência do usuário

---

### 🔄 Restore

O TeamX também foi projetado pensando na reversibilidade das alterações.

Sempre que possível, as modificações realizadas podem ser restauradas para permitir que o usuário tenha maior controle sobre o sistema.

> **O objetivo não é simplesmente modificar o Windows. É permitir que você decida como o Windows deve funcionar.**

---

## 📊 Tudo em um único aplicativo

O TeamX centraliza diferentes ferramentas em uma interface única.

```text
TeamX
│
├── Dashboard
├── Optimizations
├── Debloat
├── Services
├── Startup
├── Tweaks
├── Scanner
├── Cleaner
├── Network
├── Game Mode
├── Restore
├── Activity
├── Account
└── Settings
```

Isso elimina a necessidade de utilizar dezenas de scripts, ferramentas diferentes e configurações espalhadas pelo sistema.

* Windows 10 22H2 ou superior
* Windows 11
* Arquitetura x64
